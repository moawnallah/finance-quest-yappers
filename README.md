# Finance Quest (Yappers)

Collabothon 2026, Commerzbank challenge: gamified financial learning for self-directed investors across life stages.

## Structure

- `frontend/` Next.js mobile-first web app
- `backend/` FastAPI + PostgreSQL
- `content/` learning content (slices, EU benchmark) + validator

## Branches

- `dev`: push directly, always add tests
- `main`: merged from `dev` periodically; merging deploys
